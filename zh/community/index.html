我们所说的 DAO

去中心化是设计，
金融永远不是。

我们采用让开放基础设施可信的 DAO 理念：社区共有、决策透明、开放参与。同时去掉制造风险的要素：代币、金库、募资与投机。

社区共有

协议、Schema 与参考实现均为 Apache-2.0 开放源码；域名与注册表是受章程治理的社区资产。

全程透明

每一项决策、投票与委员会记录都公开、可复核，不存在闭门决策。

按贡献加权

影响力来自可验证的工作：评审、实现、复现、适配器与 RFC 贡献。贡献不能被购买。

绝不涉金融

没有代币、没有 NFT、没有金库、没有募资。DAO 理念只用于治理，不用于金钱。

决策如何产生

提案。
辩论。
留档。
决定。

  1. 01

    提案

    以 RFC 标签提交 KGP-RFC 拉取请求。协议、线格式、安全属性或治理的任何规范变更都必须走这条路。

  2. 02

    评议

    提案至少公开 14 天，问题、异议与替代方案全部记录在 PR 中。

  3. 03

    社区表决

    讨论汇总后进行留档投票。投票为咨询性质，按贡献记录加权，绝不按金额。

  4. 04

    委员会终审

    委员会先核对利益冲突，再投票；以绝对多数接受、驳回或取代提案。

  5. 05

    接受

    被接受的 RFC 合入并进入路线图，后续 RFC 可以取代它。

必须披露利益冲突，利益相关方不得对自己的提案投决定性一票；安全关键变更至少需要两名维护者评审，紧急修复在 72 小时内补审。

如何加入

第一次贡献，
是最难的一次。

  1. 01

    阅读文档

    先读 CONTRIBUTING.md 与治理章程，让贡献落在既定范围内。

  2. 02

    找到真实缺口

    认领 good-first issue、复现 Machine Permission Test、评审公开 RFC，或提出适配器。

  3. 03

    提交 PR

    小而精确、可测试的改动；必需 CI 通过；安全敏感变更需两名维护者评审。

  4. 04

    积累记录

    被合并的工作会公开留档。声誉来自可验证的工作，而不是金钱。
