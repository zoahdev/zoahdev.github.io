什么是物理 AI 授权？

物理 AI 授权是这样一个过程：在机器执行现实世界动作之前，判断并证明某个智能体是否被允许让某台机器，在限定的目的和时间内执行某个具体动作。

协议流程

  • 1. 智能体提交动作请求（谁、对什么、做什么、为什么、何时）；
  • 2. 策略引擎按签名策略评估，默认拒绝；
  • 3. 通过后签发短时、一次性能力；
  • 4. 执行器旁边的本地门禁原子校验能力并消费（防重放、崩溃持久）；
  • 5. 执行后产生签名哈希链收据，绑定请求、能力、传感器证据与义务结果。

它证明什么、不证明什么

签名收据证明「受信执行器的签名协议记录完整一致」，它不独立证明物理世界的真实。KineGrant 不是操作系统、运动规划器、功能安全控制器或法律权威。

关键属性

  • 一次性 + 原子防重放；
  • 调用方自持信任锚，未认证策略源只能 deny；
  • Ed25519 + ML-DSA-65 后量子签名；
  • Merkle 选择性披露与短时轮换标识（隐私最小化）；
  • Python / JS / Go 三实现互操作，结论可在浏览器比对。
