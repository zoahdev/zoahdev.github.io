给物理 AI 的开放授权与问责协议

KineGrant 决定并证明：某个智能体是否被允许让某台机器在现实世界中执行某个动作。核心流程：动作请求 → 策略评估 → 短时一次性能力 → 本地门禁原子校验 → 签名哈希链收据。任何证据都可以在浏览器里离线复核，不依赖任何中心化服务。

参考实现 v2.55.0 浏览器可复核证据 33 类 Python 测试 484 OK 一致性 23/23 MPT 22/22 红队 11/11

为什么需要 KineGrant

执行前授权

机器人动手前，必须先拿到由策略引擎签发的短时一次性能力；本地门禁只认签名与绑定关系，默认拒绝一切。

执行后问责

每次执行产生签名、哈希链收据，审计员可在浏览器里逐环复核，不需要信任执行方。

隐私最小化

支持 Merkle 选择性披露：只出示必要字段也能证明它们属于原始证据；短时轮换标识避免长期关联。

后量子就绪

签名同时支持 Ed25519 与 ML-DSA-65（FIPS 204 实验性），默认拒绝未认证来源。

三实现互操作

Python 参考实现、零依赖 JavaScript、纯标准库 Go，三者交叉验证进 CI，结论可在浏览器比对。

开放与克制

Apache-2.0，主动对齐 ODRL、IEEE 7012、WoT、ROS2、OPC UA、Matter；明确不做代币、区块链与功能安全认证。
