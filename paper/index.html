KineGrant 协议概览

KineGrant 为「物理 AI」提供开放、可验证的授权与问责层。当前版本：参考实现 v2.55.0（Apache-2.0），稳定线格式 1.0。

核心设计

  • 一次性的短时能力 + 原子消费 + 崩溃持久防重放；
  • 签名哈希链收据，绑定策略、请求、能力、证据与义务；
  • 默认拒绝、严格 fail-closed 适配器；
  • 三实现（Python/JS/Go）互操作与浏览器可复核证据链。

治理与路线

规格、威胁模型、一致性套件（L1-L4，23 项可执行标记）、Machine Permission Test（22 用例）与 RFC 流程均在 GitHub 仓库。
