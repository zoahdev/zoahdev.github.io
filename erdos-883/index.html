Exact mathematical statement

For every natural number n and every A ⊆ {1,…,n} with |A| > floor(n/2) + floor(n/3) − floor(n/6), the induced coprime graph G(A) contains a simple cycle of every odd length ℓ satisfying 3 ≤ ℓ ≤ floor(n/3) + 1.

The repository splits the proof into exact finite certificates for n < 200000 and an analytic argument for n ≥ 200000. Its final theorem is Erdos883Verified.erdos883_firstQuestion.
